## 1. Как всё устроено

Клиент может заказать растения **на сайте** или **в Telegram-боте** — неважно где. Все заказы попадают в **одну общую админку**, которую видят админ и менеджеры.

- **Сайт** — витрина: каталог с фото, корзина, оформление заказа.
- **Бот** — тоже магазин + вся работа с заказами для админа.
- **Чат** — клиент может написать с сайта или из бота, всё приходит менеджерам в одно место.

## 2. Как проходит заказ (самое важное)

| Шаг | Что происходит | Кто что делает |
|---|---|---|
| 1 | Клиент оформляет заказ | Клиент |
| 2 | Заказ появляется в админке | Админ проверяет наличие товара |
| 3 | Клиент переводит **предоплату 30%** и загружает чек | Клиент |
| 4 | Чек проверяется автоматически | Если всё совпало — подтверждается само; если есть сомнения — приходит админу на проверку |
| 5 | Предоплата подтверждена | Админ нажимает **«💰 Запросить остаток»** в карточке заказа |
| 6 | Клиент доплачивает **70%** и снова загружает чек | Клиент |
| 7 | Заказ собран и отправлен | Админ отмечает «Заказ отправлен» и вводит трек-номер |
| 8 | Клиент получил растения | Админ нажимает **«✅ Завершить заказ»** |

В любой момент заказ можно **отменить** — товар вернётся на склад автоматически.

## 3. Для админа

### 3.1. Как открыть админку

Напишите боту команду **`/admin`**. Доступ есть только у админа.

Главное меню:

| Кнопка | Что внутри |
|---|---|
| 📋 **Заказы** | Список всех заказов |
| 💳 **Проверка оплат** | Чеки, которые надо подтвердить вручную |
| 📦 **Заказы на отправку** | Оплаченные заказы, ждущие отправки |
| 🌱 **Товары** | Добавление и скрытие позиций каталога |
| 💰 **Цены** | Цена по умолчанию для каждой категории |
| 📊 **Статистика** | Сводка по заказам |
| 📥 **Выгрузка Excel** | Все заказы одним файлом |
| ⚙️ **Настройки** | Реквизиты, доставка, контакты |

### 3.2. Работа с заказом

Откройте заказ из списка «📋 Заказы». Доступные действия:

- **💰 Запросить остаток** — после подтверждения предоплаты. Клиенту приходит ссылка на доплату 70%.
- **✅ Завершить заказ** — клиент получил заказ, история закрыта.
- **🚫 Отменить заказ** — отмена, товар возвращается на склад.
- **💬 Написать клиенту** — сообщение уйдёт клиенту в бот или на его страницу на сайте.

### 3.3. Проверка оплат

Чеки проверяются **автоматически**: система читает сумму, дату и получателя и сверяет с заказом.

- ✅ Всё совпало → оплата подтверждается сама, клиенту приходит уведомление.
- ⚠️ Есть сомнения → чек приходит вам в бот с пояснением и кнопками:
  - **«✅ Оплата подтверждена»** — принимаем вручную;
  - **«❌ Оплата не подтверждена»** — клиенту уйдёт отказ с вашим комментарием, заказ снова ждёт чек.
- 🔁 Один и тот же чек дважды принять нельзя — дубликаты отклоняются сами.

### 3.4. Отправка заказа

«📦 Заказы на отправку» → выберите заказ → **«📦 Заказ отправлен»** → введите трек-номер 5Post → клиенту придёт уведомление с треком.

### 3.5. Товары

«🌱 Товары» → выберите категорию:

- **Скрыть/показать позицию** — кнопка-переключатель напротив позиции.
- **Добавить позицию** — бот пошагово спросит: фото → цену → остаток.
- **Инфографика категории** — картинка-обложка для раздела.

### 3.6. Настройки (⚙️)

Всё меняется прямо в боте, ничего перезапускать не нужно:

- стоимость доставки;
- реквизиты для оплаты (карта, телефон СБП, имя получателя);
- адрес самовывоза;
- контакт менеджера, который видят клиенты.

### 3.7. Как добавить менеджера

Через веб-админку `/admin` — раздел сотрудников: имя, логин, пароль, Telegram ID (сотрудник может узнать его у бота @userinfobot).

После этого у менеджера появятся личные реф-ссылки и кабинет.

| 📦 **Заказы** | Заказы ваших клиентов |
| 📥 **Выгрузить Excel** | Ваши клиенты и заказы файлом |

### 4.2. Как работают реф-ссылки

- Размещайте свои ссылки где угодно: соцсети, визитки, рассылки.
- Клиент, впервые пришедший по вашей ссылке, **закрепляется за вами навсегда**.
- Все дальнейшие заказы этого клиента считаются вашими — они видны в статистике.

### 4.3. Как отвечать клиентам

Клиент пишет с сайта или из бота — всё приходит вам в бот:

1. Приходит уведомление: «💬 Новое сообщение от клиента».
2. Нажимаете кнопку **«✍️ Ответить клиенту»**.
3. Пишете ответ обычным сообщением. Передумали — отправьте `/cancel`.
4. Ответ доставляется клиенту: в бот или на его страницу на сайте.

Вся история переписки хранится вместе.

- **Страница оплаты** — сумма, реквизиты, загрузка чека.
- При повторном заказе форма уже заполнена данными клиента.

## 6. Типовые ситуации

**«Я оплатил, а заказ не подтвердился»**
Чек не прошёл автопроверку. Откройте «💳 Проверка оплат» — если чек там, подтвердите вручную. Если чека нет — попросите клиента загрузить его ещё раз по ссылке оплаты.

**Клиент потерял свою ссылку на заказы**
Если он заходит с того же телефона — ссылка сама появится в шапке сайта («Мои заказы»). Если с другого устройства — найдите его заказ в админке и отправьте ссылку через «💬 Написать клиенту».

**Клиент просит изменить заказ**
Состав заказа после оформления не редактируется. Отмените заказ и попросите оформить заново, либо договоритесь в чате и учтите изменение при отправке.

**Нужно поменять реквизиты или стоимость доставки**
`/admin` → ⚙️ Настройки — меняется сразу, на лету.

**Что-то сломалось, бот не отвечает**
Напишите разработчику.

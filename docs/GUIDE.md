# 📖 Гайд по боту и сайту питомника

Простая инструкция для всех, кто работает с заказами: админа и менеджеров.
Обновляйте этот файл, когда в боте или на сайте что-то меняется.

---

## 1. Как всё устроено (одной картинкой словами)

```
Клиент ──► САЙТ (каталог, корзина, оформление) ─┐
Клиент ──► TELEGRAM-БОТ (каталог, заказ) ───────┼──► ОДНА общая база заказов
Клиент ──► MINI APP в Telegram ─────────────────┘
                                                       │
             Менеджеры и админ видят заказы в боте ◄───┘
             и переписываются с клиентами в общем чате
```

- **Сайт** — витрина: каталог с фото, корзина, форма заказа.
- **Бот** — тоже магазин + вся работа с заказами (админка).
- **Mini App** — сайт, открытый внутри Telegram (кнопка «🌱 Открыть магазин»).
- Заказ, сделанный в любом месте, попадает в одну общую админку.

---

## 2. Жизненный цикл заказа (самое важное)

| Шаг | Что происходит | Кто что делает |
|---|---|---|
| 1 | Клиент оформляет заказ (сайт или бот) | Клиент |
| 2 | Заказ появляется в админке, статус «Ждёт предоплату» | Админ проверяет наличие |
| 3 | Клиент переводит **предоплату 30%** и загружает чек | Клиент |
| 4 | Система проверяет чек автоматически | Если всё совпало — подтверждается само; если есть сомнения — приходит админу на ручную проверку |
| 5 | Предоплата подтверждена | Админ нажимает **«💰 Запросить остаток»** в карточке заказа |
| 6 | Клиент доплачивает **70%** и снова загружает чек | Клиент + та же проверка чека |
| 7 | Заказ собран и отправлен | Админ: «📦 Заказы на отправку» → «Заказ отправлен» → вводит трек-номер |
| 8 | Клиент получил растения | Админ: «✅ Завершить заказ» |

В любой момент заказ можно **«🚫 Отменить»** — остатки товара вернутся на склад автоматически.

## 3. Для админа

### 3.1. Как попасть в админку

Напишите боту команду **`/admin`**. Работает только с Telegram-аккаунтов, чьи ID прописаны в настройках сервера (`ADMIN_IDS`).

Главное меню админки:

| Кнопка | Что внутри |
|---|---|
| 📋 **Заказы** | Список всех заказов, карточка каждого заказа |
| 💳 **Проверка оплат** | Чеки, которые система не смогла подтвердить автоматически |
| 📦 **Заказы на отправку** | Оплаченные заказы, ждущие отправки |
| 🌱 **Товары** | Добавление и скрытие позиций каталога |
| 💰 **Цены** | Цена по умолчанию для каждой категории |
| 📊 **Статистика** | Сводка по заказам |
| 📥 **Выгрузка Excel** | Все заказы одним файлом |
| ⚙️ **Настройки** | Реквизиты, доставка, контакты |

### 3.2. Работа с заказом (карточка заказа)

Откройте заказ из списка «📋 Заказы». Доступные действия:

- **💰 Запросить остаток** — после подтверждения предоплаты. Клиенту приходит ссылка на доплату 70%.
- **✅ Завершить заказ** — клиент получил заказ, история закрыта.
- **🚫 Отменить заказ** — отмена с возвратом остатков.
- **💬 Написать клиенту** — сообщение уйдёт клиенту (в бот, а если он с сайта — на его персональную страницу).

### 3.3. Проверка оплат

Чеки проверяются **автоматически**: система читает сумму, дату, получателя и номер операции и сверяет с заказом.

- ✅ Совпало → оплата подтверждается сама, клиент и админы получают уведомление.
- ⚠️ Есть сомнения → чек приходит вам в бот с пояснением причин и кнопками:
  - **«✅ Оплата подтверждена»** — всё в порядке, принимаем вручную;
  - **«❌ Оплата не подтверждена»** — бот попросит комментарий, клиенту уйдёт отказ с вашим текстом, заказ снова ждёт чек.
- 🔁 Дубликат чека (тот же файл или номер операции) отклоняется автоматически.

### 3.4. Отправка заказа

«📦 Заказы на отправку» → выберите заказ → **«📦 Заказ отправлен»** → бот попросит трек-номер 5Post → клиенту приходит уведомление с треком.

### 3.5. Товары

«🌱 Товары» → выберите категорию:

- **Скрыть/показать позицию** — кнопка-переключатель напротив позиции.
- **Добавить позицию** — бот пошагово спросит: фото → номер фото → цену → остаток.
- **Инфографика категории** — картинка-обложка для раздела.

### 3.6. Настройки (⚙️)

Всё редактируется прямо в боте, без перезапуска:

- стоимость доставки;
- карта, телефон СБП, кошелёк, имя получателя — **это то, что сверяет автопроверка чеков**;
- текст реквизитов (показывается клиенту);
- адрес самовывоза;
- контакт менеджера (показывается клиентам).

### 3.7. Веб-админка (сайт `/admin`)

Адрес: `https://<ваш-домен>/admin`. Вход по логину и паролю сотрудника с правами админа.

Здесь управляются **менеджеры**: добавить сотрудника, сбросить пароль, перевыпустить секретную ссылку, посмотреть общую статистику.

### 3.8. Как добавить менеджера

Два способа:

1. **Через веб-админку** `/admin` — раздел сотрудников, «добавить»: имя, логин, пароль, Telegram ID.
2. **Через скрипт на сервере:**
   ```bash
   python scripts/add_employee.py "Анна" --tg 123456789   # создать
   python scripts/add_employee.py --list                  # список со ссылками
   ```

Telegram ID сотрудник может узнать у бота @userinfobot.

## 4. Для менеджера (сотрудника)

### 4.1. Ваш кабинет

В боте: главное меню → **«👤 Мой кабинет»** (видна только сотрудникам).

| Кнопка | Что делает |
|---|---|
| 🔗 **Реф-ссылки** | Ваши личные ссылки: на бота, на мини-ап, на сайт |
| 📊 **Статистика** | Сколько людей перешло по вашим ссылкам и сколько заказало |
| 👥 **Клиенты** | Список закреплённых за вами клиентов |
| 📦 **Заказы** | Заказы ваших клиентов |
| 📥 **Выгрузить Excel** | Ваши клиенты и заказы файлом |

Тот же кабинет есть на сайте: `https://<ваш-домен>/cabinet` — вход по логину и паролю, которые выдал админ. В Mini App есть экран «Мои клиенты».

### 4.2. Как работают реф-ссылки

- У вас три личные ссылки — на бота, на мини-ап и на сайт. Размещайте их где угодно: соцсети, визитки, рассылки.
- Клиент, впервые пришедший по вашей ссылке, **закрепляется за вами навсегда** (работает правило «первый источник побеждает»: если клиент уже приходил по чужой ссылке, перезаписать его нельзя).
- Все дальнейшие заказы этого клиента считаются вашими — они видны в статистике.

### 4.3. Как отвечать клиентам (общий чат)

Клиент может написать вам **с сайта или из бота** — всё приходит в одно место: вам в бот.

1. Вам приходит уведомление: «💬 Новое сообщение от клиента» с текстом.
2. Нажимаете под ним кнопку **«✍️ Ответить клиенту»**.
3. Пишете ответ обычным сообщением. Передумали — отправьте `/cancel`.
4. Ответ доставляется клиенту: если у него есть Telegram — в бот; если он с сайта — на его персональную страницу (бот сообщит об этом и даст ссылку).

Вся история переписки хранится вместе: и сообщения с сайта, и из бота.

## 5. Сайт глазами клиента (чтобы вы понимали, что видит клиент)

- **Каталог и корзина** — корзина сохраняется на устройстве клиента, ничего не пропадает при обновлении страницы.
- **Оформление** — ФИО, телефон, город, пункт 5Post, комментарий.
- **После заказа** клиент получает **персональную ссылку** (`/client/...`). Там: его заказы со статусами, кнопки оплаты и **чат с вами**. Ссылка показывается на экране успеха и сохраняется в браузере клиента — при повторном визите в шапке сайта появляется «Мои заказы».
- **Страница оплаты** (`/pay/...`) — сумма, реквизиты, загрузка чека и тот же чат.
- Повторный заказ клиента автоматически привязывается к его профилю, а форма уже заполнена его данными.

## 6. Типовые ситуации

**Клиент говорит «я оплатил, а заказ не подтвердился»**
Скорее всего, чек не прошёл автопроверку. Откройте «💳 Проверка оплат» — если чек там, подтвердите вручную. Если чека нет — попросите клиента загрузить его ещё раз по ссылке оплаты.

**Чек-фото не распознаётся совсем**
На сервере должен стоять tesseract: `apt install tesseract-ocr tesseract-ocr-rus`. Без него все чеки-картинки идут на ручную проверку (это не поломка, но ручной работы больше).

**Клиент потерял персональную ссылку**
Если он заходит с того же браузера — ссылка сама появится в шапке сайта («Мои заказы»). Если с другого устройства — найдите его заказ в админке и отправьте ссылку через «💬 Написать клиенту».

**Клиент просит изменить заказ**
Состав заказа после оформления не редактируется. Отмените заказ (🚫) и попросите клиента оформить заново, либо договоритесь в чате и учтите изменение при отправке.

**Бот «молчит»**
На сервере: проверьте, что процесс запущен, и прогоните `python tests/smoke_test.py` — в конце есть живая проверка связи с Telegram.

**Нужно поменять реквизиты/доставку**
`/admin` → ⚙️ Настройки — всё меняется на лету, перезапуск не нужен.
